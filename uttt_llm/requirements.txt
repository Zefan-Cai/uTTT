# uTTT language-modeling dependencies.
#
# Install order matters:
#   pip install torch==2.8.0 --index-url https://download.pytorch.org/whl/cu128
#   pip install -r uttt_llm/requirements.txt
#   pip install flash-attn --no-build-isolation
#
# flash-attn is REQUIRED here, not optional: every fast-weight model imports
# flash_attn at module scope, so nothing in flame/custom_models/ imports
# without it. It cannot live in this file because it needs torch present at
# build time, which pip's build isolation prevents.
#
# Reference environment, verified working:
#   Python 3.10, CUDA 12.8, torch 2.8.0+cu128, triton 3.4.0

# --- training stack ---

# --- version caveat -------------------------------------------------------

# 0.1.0 and flash-linear-attention 0.5.0 (torchtitan 0.2.x is incompatible
# with torch 2.8 — it requires the torch>=2.9 varlen attention APIs).
